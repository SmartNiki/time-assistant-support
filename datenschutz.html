Datenschutzerklärung

Informationen zur Verarbeitung von Daten in der iOS-App Time Assistant und auf dieser Support-Website.

1. Verantwortlicher

Niklas Baumgartner
E-Mail: niklasbaumgartner@icloud.com

2. Verarbeitung von Daten in der App

Time Assistant dient der lokalen Erfassung und Verwaltung von Arbeitszeiten. Die in der App eingegebenen Arbeitszeiten sowie die zugehörigen Einstellungen werden ausschließlich auf dem verwendeten Gerät gespeichert.

Die App übermittelt diese Daten nicht an den Entwickler oder an einen von ihm betriebenen Server. Es werden keine Benutzerkonten angelegt und innerhalb der App keine Analyse-, Werbe- oder Tracking-Dienste eingesetzt.

3. Berechtigungen

Time Assistant greift nur auf Gerätefunktionen zu, die für die bereitgestellten Funktionen erforderlich sind. Falls eine Systemberechtigung benötigt wird, fragt die App zuvor über den entsprechenden Dialog des Betriebssystems danach.

4. Löschung der Daten

Da die Daten lokal auf dem Gerät gespeichert werden, können sie durch das Löschen der entsprechenden Einträge in der App oder durch das Deinstallieren der App entfernt werden. Eine Wiederherstellung kann abhängig von einer durch den Nutzer eingerichteten Gerätesicherung möglich sein.

5. Dienste von Apple

Beim Herunterladen und Verwenden der App kann Apple Daten in eigener Verantwortung verarbeiten, etwa im Zusammenhang mit dem App Store, dem Betriebssystem oder Gerätesicherungen. Weitere Informationen enthält die Datenschutzrichtlinie von Apple.

6. Zukünftige iCloud-Synchronisierung

Time Assistant verwendet derzeit keine iCloud-Synchronisierung. Sollte diese Funktion zukünftig eingeführt werden, wird diese Datenschutzerklärung vor der Veröffentlichung der betreffenden App-Version entsprechend aktualisiert.

7. Diese Support-Website

Diese Website stellt statische Support-Inhalte bereit. Im Website-Code sind keine Analysewerkzeuge, Werbetracker, Kontaktformulare oder Cookies eingebunden. Schriftarten werden vom Gerät geladen; es werden keine externen Schriftanbieter aufgerufen.

Die Website wird über GitHub Pages ausgeliefert. GitHub protokolliert und speichert beim Besuch IP-Adressen zu Sicherheitszwecken – auch ohne Anmeldung. Weitere Informationen findest du in der Datenschutzerklärung von GitHub und den Hinweisen zu GitHub Pages.

8. Kontakt

Bei Fragen zum Datenschutz kannst du dich per E-Mail an niklasbaumgartner@icloud.com wenden.

9. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann angepasst werden, wenn sich die Funktionen der App oder rechtliche Anforderungen ändern. Die jeweils aktuelle Fassung wird unter derselben Internetadresse bereitgestellt.
