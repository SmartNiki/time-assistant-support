Häufige Fragen

Die wichtigsten Antworten an einem Ort.

Die App reagiert nicht. Was kann ich tun?

Schließe Time Assistant und öffne die App erneut. Prüfe anschließend im App Store, ob ein Update verfügbar ist. Falls das Problem bleibt, starte dein iPhone neu. Lösche die App nicht vorschnell: Dabei können lokal gespeicherte Daten verloren gehen.

Welche Angaben helfen bei einer Support-Anfrage?

Nenne dein iPhone-Modell, die iOS-Version und möglichst die App-Version. Beschreibe kurz, was du tun wolltest, was stattdessen passiert ist und wie sich das Problem wiederholen lässt. Ein Screenshot kann helfen; verdecke bitte persönliche Informationen.

Wie aktualisiere ich Time Assistant?

Öffne den App Store und suche nach Time Assistant. Wenn eine neue Version für dein Gerät verfügbar ist, kannst du sie über „Aktualisieren“ installieren.

Wo finde ich Informationen zum Datenschutz?

Auf der Datenschutz-Seite erfährst du, wie Time Assistant Daten speichert und welche Daten beim Aufruf dieser Website verarbeitet werden.

Wie kann ich einen Fehler oder eine Idee melden?

Schreibe an niklasbaumgartner@icloud.com. Beschreibe bei einem Fehler auch das erwartete Verhalten. Für einen Verbesserungsvorschlag reicht eine kurze Erklärung, wobei dir die Funktion helfen würde.
